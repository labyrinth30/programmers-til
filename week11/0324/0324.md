## BoardList 생성

가장 상단에는 여러 게시판을 선택할 수 있는 탭 형태의 `BoardList` 를 만들어요.
게시판 목록은 배열을 기반으로 순회해서 화면에 그려요.

스타일은 `@vanilla-extract/css` 를 사용해 적용해요.
이 방식은 `:hover` 같은 의사 클래스도 함께 다루기 편해요.

```ts
export const addButton = style({
  color: vars.color.brightText,
  fontSize: vars.fontSizing.T2,
  cursor: "pointer",
  marginLeft: vars.spacing.big1,
  ":hover": {
    opacity: 0.8,
  },
});
```

상태에 따라 다른 클래스를 적용할 때는 `clsx` 를 활용해요.
현재 선택된 게시판인지 아닌지에 따라 스타일을 나눠서 적용할 수 있어요.

```tsx
className={clsx(
  {
    [boardItemActive]:
      boardArray.findIndex((b) => b.boardId === activeBoardId) === idx,
  },
  {
    [boardItem]:
      boardArray.findIndex((b) => b.boardId === activeBoardId) !== idx,
  }
)}
```

## SideForm 생성

`SideForm` 도 함께 만들어요.
입력 폼이 열렸을 때는 바로 입력할 수 있도록 포커스를 주고, 포커스를 잃었을 때의 동작도 같이 처리해요.

`onBlur` 는 요소가 포커스를 잃을 때 실행되는 이벤트예요.
입력 UI 를 닫거나 상태를 바꿔야 할 때 유용하게 사용할 수 있어요.

```tsx
<input
  autoFocus
  onBlur={handleBlur}
  value={title}
  onChange={handleChange}
/>
```

## 새로운 게시판 추가하기

새 게시판은 이름을 입력한 뒤 추가 버튼을 눌렀을 때 생성되도록 구현해요.
여기서 한 가지 주의할 점은 `onBlur` 와 `onClick` 의 실행 순서예요.

입력창에서 버튼을 클릭하면 `onClick` 보다 `onBlur` 가 먼저 실행돼요.
그래서 입력창이 먼저 닫혀 버리면 클릭 이벤트가 정상적으로 처리되지 않을 수 있어요.
이 경우에는 `onClick` 대신 `onMouseDown` 을 사용해 먼저 이벤트를 처리해요.

```tsx
<button onMouseDown={handleAddBoard}>추가</button>
```

게시판을 추가하는 작업은 `store` 의 상태를 변경하는 일이기 때문에 `dispatch` 를 사용해요.
이와 함께 `slice` 에도 새로운 액션을 추가해요.

또한 게시판마다 고유한 식별자가 필요하므로 `uuid` 를 사용해 아이디를 생성해요.

```ts
addBoard: (state, action: PayloadAction<{ title: string }>) => {
  state.boardArray.push({
    boardId: uuidv4(),
    title: action.payload.title,
  });
};
```
