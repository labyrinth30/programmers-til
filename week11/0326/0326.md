


지난 시간에 이어 업무 관리 프로젝트를 계속 진행해 볼게요. 이번 시간에는 화면에 드래그 앤 드롭 기능을 추가하고, Firebase를 활용한 로그인과 로그아웃 기능, 그리고 호스팅을 이용한 최종 배포까지 정리해 볼게요.

## 드래그 앤 드롭 기능 추가

`react-beautiful-dnd` 라이브러리를 사용해 화면에서 업무(Task)를 자유롭게 이동시키는 기능을 추가했어요. 라이브러리 사용을 위한 사전 연습 코드 및 전체 프로젝트 코드는 깃허브 레포지토리에서 확인할 수 있어요.

## Firebase 연동 및 로그인, 로그아웃

Firebase 사이트에서 새로운 프로젝트를 생성하면 초기 설정에 필요한 코드와 가이드를 확인할 수 있어요. 이번 프로젝트에서는 Google 계정을 연동한 로그인을 구현했어요. 프로젝트 생성 후 Authentication 탭으로 들어가 로그인 방법 중 Google을 선택해 주면 기본 준비가 끝나요.

실제 프로젝트 코드에서는 Firebase 라이브러리에서 제공하는 함수들을 활용해요. 로그인은 `signInWithPopup()` 함수를 사용하고, 로그아웃은 `signOut()` 함수를 사용해서 간단하게 구현할 수 있어요. 

## Github Actions를 이용한 배포

Firebase 호스팅과 Github Actions를 연동해 프로젝트를 배포할 수 있어요. 먼저 터미널에서 Firebase 관련 도구를 전역으로 설치하고 로그인을 진행해요.

```bash
# 전역으로 firebase-tools 설치
npm i -g firebase-tools

# firebase 로그인 (실행 시 브라우저 인증 창 표시)
firebase login
```

브라우저에서 로그인이 성공적으로 완료되면, 아래 명령어를 통해 프로젝트 초기 설정을 진행해요.

```bash
# firebase 설정 초기화
firebase init
```

명령어를 실행하면 터미널에서 여러 설정 항목을 선택할 수 있는 화면이 나와요. 방향키와 스페이스바를 이용해 호스팅 기능과 Github Actions 연동 옵션을 선택하여 설정을 마무리하면 돼요. 관련된 세부 설정 내용은 Firebase 공식 홈페이지의 문서를 참고하면 좋아요.
