## 도서 전체 조회, 상세 도서 조회
도서 전체 조회 api를 위해 select books하는 코드를 추가했는데, 명세서에서 요구하는 것보다 더 많은 칼럼이 리턴되었어요.
저는 당연히 select * 를 고칠 줄 알았는데, 인강에서는 프론트에서 알아서 가공시키게 할 것이라고 해서 흠...이게 맞나 싶었어요.
BookListDTO랑 BookDetailDTO를 따로 만들어서 해당 DTO에 맞게 가공하는 것이 올바른 백엔드 코드라고 생각해요.
하지만 일단 강의에 따라가야하니 모든 정보를 반환하도록 구현했어요.
![](https://velog.velcdn.com/images/ayeon0/post/b7086557-98df-4400-a7ba-b6046b94c731/image.png)
![](https://velog.velcdn.com/images/ayeon0/post/e4875626-2256-4070-b142-350982d781f9/image.png)
```js
export const findBooks = (req, res) => {
    const sql = 'SELECT * FROM books';
    db.query(sql, (err, results) => {
        if (err) return res.status(StatusCodes.INTERNAL_SERVER_ERROR).json({message: err.message});
        return res.status(StatusCodes.OK).json(results);
    });
};

export const findBookById = (req, res) => {
    const { id } = req.params;
    const sql = 'SELECT * FROM books WHERE id = ?';
    db.query(sql, id, (err, results) => {
        if (err) return res.status(StatusCodes.INTERNAL_SERVER_ERROR).json({message: err.message});
        if (results.length === 0) return res.status(StatusCodes.NOT_FOUND).end();
        return res.status(StatusCodes.OK).json(results[0]);
    });
};
```

## 카테고리별 도서 목록 조회
```js
export const findBooks = (req, res) => {
    const { categoryId } = req.query;
    if ( categoryId ) {
        const sql = 'SELECT * FROM books WHERE category_id = ?';
        db.query(sql, categoryId, (err, results) => {
            if (err) return res.status(StatusCodes.INTERNAL_SERVER_ERROR).json({message: err.message});
            return res.status(StatusCodes.OK).json(results);
        });
    } else {
    const sql = 'SELECT * FROM books';
    db.query(sql, (err, results) => {
        if (err) return res.status(StatusCodes.INTERNAL_SERVER_ERROR).json({message: err.message});
        return res.status(StatusCodes.OK).json(results);
    });
    }
};
```
쿼리 스트링의 유무에 따라 분기별로 db에서 데이터를 가져오도록 바꾸었어요.
